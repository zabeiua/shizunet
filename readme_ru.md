# ShizuNet (Shizuku Proxy & Configuration Link Generator)

[Read in English 🇬🇧](README.md) | [Скачать последний артефакт 📥](https://github.com/zabeiua/shizunet/actions/runs/27436986916/artifacts/7600343173)

**ShizuNet** — это удобная Android-утилита, разработанная для упрощения раздачи VPN и прокси-соединений через мобильную точку доступа (SoftAP / Tethering). Приложение автоматизирует процесс определения IP-адреса сетевого шлюза точки доступа и генерирует готовые конфигурационные профили и QR-коды для популярного прокси-клиента **Sing-Box**.

Благодаря интеграции с **Shizuku**, приложение запрашивает привилегированный доступ к системному шеллу для точного и мгновенного считывания таблиц маршрутизации Android. Это исключает необходимость вручную искать сетевой адрес шлюза в сторонних терминалах.

## 🌟 Основные Возможности

* **Интеграция с Shizuku (`ip r`)**:
  Безопасное и быстрое считывание таблицы маршрутизации Android из привилегированного шелла для автоматического определения IP-адреса беспроводного интерфейса точки доступа (`ap0`, `wlan1` или `wlan0`).
* **Генерация HTTP-профилей Sing-Box**:
  Автоматическое формирование структурированного и полностью валидного JSON-профиля формата Sing-Box для клиентских устройств.
* **Гибкая маршрутизация по правилам (GeoIP/Geosite)**:
  Поддержка динамической настройки правил маршрутизации. По умолчанию правила обхода настроены на российский сегмент (`ru`): гео-зоны `ru` (префиксы geoip/geosite) направляются **напрямую** (`direct`), минуя прокси, а весь остальной трафик идет через HTTP-прокси.
* **Импорт в один клик и QR-коды**:
  * Одно устройство генерирует QR-код со схемой `sing-box://import?config=...`
  * Клиентское устройство (ноутбук, Android TV, консоль, ПК), подключенное к вашей точке доступа, мгновенно считывает конфигурацию по QR-коду или по скопированной ссылке.
* **Современный UI**:
  Минималистичный интерфейс на Jetpack Compose с темной палитрой (Slate-900), индикатором статуса службы Shizuku и логом обратной связи выполнения команд.

## 🛠️ Как это работает в сценарии раздачи VPN / Proxy

Если ваше Android-устройство подключено к VPN, стандартными средствами Android раздать это VPN-подключение по Wi-Fi на другие устройства невозможно (трафик клиентов идет напрямую через мобильную сеть/провайдера). 

Схема обхода:
1. Вы запускаете локальный HTTP/Socks прокси-сервер на телефоне (например, через v2rayNG, Nekobox, Sing-Box и др.) на порту `12334`.
2. Включаете **Мобильную точку доступа** на телефоне.
3. Соединяете клиентские устройства с точкой доступа Wi-Fi вашего телефона.
4. Открываете **ShizuNet** -> Нажимаете **Auto-Detect Hotspot Gateway IP**.
5. Утилита находит адрес шлюза (например, `192.168.43.1`), подставляет порт `12334` и генерирует QR-код.
6. Клиент сканирует QR-код в своем приложении Sing-Box, импортирует его и получает полноценный доступ в сеть с настроенным обходом блокировок и маршрутизацией!

## 🚀 Инструкция по использованию

1. **Запуск Shizuku**:
   Убедитесь, что на вашем устройстве установлено и запущено приложение [Shizuku](https://shizuku.rikka.app/). Активируйте Shizuku через Wi-Fi отладку (LADB) или ROOT-доступ.
2. **Предоставление прав**:
   Откройте **ShizuNet** и нажмите **Grant Shizuku Privilege Shell** (или "Check / Connect Shizuku"). В появившемся системном диалоге Shizuku подтвердите предоставление прав.
3. **Определение Gateway IP**:
   Включите мобильную точку доступа. Нажмите кнопку **Auto-Detect Hotspot Gateway IP**. В консольном логе появится сообщение об успешном резолве шлюза (например, `192.168.43.1` или `192.168.44.1`).
4. **Конфигурирование**:
   * При необходимости отредактируйте IP шлюза или порт (по умолчанию задан HTTP-порт `12334`).
   * Измените гео-код (например, `ru` для РФ или `ir` для Ирана), который будет использовать правило прямого подключения (`direct`).
5. **Экспорт**:
   * Нажмите **Copy Link**, чтобы скопировать ссылку быстрого импорта `sing-box://import?...`.
   * Нажмите **Copy JSON**, чтобы скопировать сырой файл конфигурации.
   * Или просто откройте QR-код на экране и отсканируйте его камерой клиентского устройства в приложении Sing-Box.

## 📦 Сборка и Релиз на GitHub (GitHub Actions CI/CD)

В репозиторий уже настроена автоматическая система сборки и публикации релизов средствами GitHub Actions (файл `.github/workflows/build.yml`).

### Локальная сборка
Чтобы собрать APK файл локально с помощью Gradle, выполните в терминале в корневой папке проекта:
```bash
./gradlew assembleDebug
# или для релизной версии
./gradlew assembleRelease
```

### Автоматическая сборка на GitHub
При каждом коммите или создании Pull Request в ветки `main`/`master` автоматически запускается рабочий процесс:
1. Gradle компилирует debug-версию приложения.
2. Собранный APK загружается в артефакты сборки (название артефакта: `ShizuNet-build-artifacts`).

### Как автоматически опубликовать релиз (GitHub Release)
Для создания полноценного релиза на GitHub выполните следующие действия:

1. **Добавьте тег версии в ваш git-репозиторий**:
   При пуше любого тега, начинающегося с буквы `v` (например, `v1.0.0`, `v1.1.2`), GitHub Actions запустит процедуру публикации релиза.
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
2. **Сборка релизного APK**:
   Рабочий процесс соберет как `debug.apk`, так и `release.apk`.
3. **Автоматическая цифровая подпись APK (Опционально)**:
   Если вы хотите, чтобы GitHub Actions автоматически подписывал релизные APK вашим личным Keystore-ключом, добавьте следующие секреты (**Secrets**) в настройки вашего репозитория GitHub (`Settings -> Secrets and variables -> Actions`):
   * `SIGNING_KEY` — Ваш файл Keystore, закодированный в Base64.
   * `ALIAS` — Алиас вашего ключа подписи.
   * `KEYSTORE_PASSWORD` — Пароль от файла Keystore.
   * `KEY_PASSWORD` — Пароль от самого ключа.
   
   *Примечание: Если эти секреты не заданы, GitHubActions автоматически соберет и прикрепит к релизу неподписанную версию (`app-release-unsigned.apk`).*
4. **Черновик Релиза (Draft Release)**:
   При успешном завершении сборки на вкладке **Releases** вашего репозитория автоматически создастся **черновик релиза (Draft Release)**.
   * К черновику будут автоматически прикреплены скомпилированные APK файлы.
   * Будет автоматически сгенерировано описание изменений (Release Notes) на основе истории ваших коммитов. Вы можете скорректировать текст черновика и нажать **Publish**, чтобы сделать релиз общедоступным.
